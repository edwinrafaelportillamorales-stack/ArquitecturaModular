# Métodos Iterativos: Jacobi y Gauss-Seidel

Descripción:
Este proyecto implementa los métodos numéricos iterativos de Jacobi y Gauss-Seidel en Java para resolver un sistema de ecuaciones lineales. El programa utiliza una arquitectura modular que separa la definición del sistema, la lógica de los métodos y la ejecución principal.

Sistema de ecuaciones
El sistema utilizado en la práctica es:
[5x+y+z=7]
[x+4y+z=6]
[x+2y+5z=8]

Parámetros de ejecución:
- Vector inicial: X(0) = [0, 0, 0]
- Tolerancia: 0.0001
- Máximo de iteraciones: 100

Resultados:
La solución exacta del sistema es:
Metodo de Jacobi:
[0.9999869210370103, 0.9999847412109375, 0.9999825613848647]

Metodo de Gauss-Seidel:
[0.9999938115800001, 1.000000151955, 1.0000011769019999]
